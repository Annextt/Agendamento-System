# 💎 Salão Elegance — Plataforma de Agendamento & Gestão
📌 Sobre o Projeto

O Salão Elegance é uma plataforma Full Stack de agendamento e gestão para salões de beleza e estética, desenvolvida com foco em escalabilidade, organização operacional e aplicação comercial real.

O sistema foi projetado para automatizar o processo de marcação de horários, centralizar informações dos clientes e oferecer controle administrativo completo, reduzindo falhas manuais e aumentando a eficiência do negócio.

Este projeto já foi validado comercialmente e utilizado como base para implementação em empresa real do setor de estética.

# 🏢 Aplicação Comercial

Este sistema foi desenvolvido como produto base replicável, podendo ser adaptado para diferentes:

Salões de beleza

Clínicas de estética

Barbearias

Estúdios de manicure

Profissionais autônomos

A estrutura permite personalização de identidade visual, serviços, valores e unidades.

# 🧠 Arquitetura do Sistema

O projeto segue arquitetura Full Stack com separação clara entre:

Interface do usuário (Front-end)

Camada de regras de negócio (API REST)

Persistência de dados (MongoDB)

# Fluxo geral:

Cliente realiza agendamento via interface.

Dados são enviados para API.

API valida informações.

Dados são persistidos no banco.

Painel administrativo consome a mesma API para gerenciamento.

# 🔁 Fluxo de Agendamento

O sistema utiliza fluxo multi-etapas estruturado:

1️⃣ Escolha do Serviço
2️⃣ Seleção de Data
3️⃣ Seleção de Horário
4️⃣ Preenchimento de Dados do Cliente
5️⃣ Confirmação e Registro no Banco

Cada agendamento registra:

Serviço escolhido

Duração

Valor

Data

Horário

Nome

Telefone

Email

# 🔐 Painel Administrativo

O sistema conta com área administrativa protegida por autenticação.

Funcionalidades:

Login com senha

Visualização completa dos agendamentos

Organização de clientes

Exclusão de agendamentos (cancelamento)

Controle e gestão centralizada

A rota administrativa é isolada da aplicação pública, garantindo segurança e separação de responsabilidades.
